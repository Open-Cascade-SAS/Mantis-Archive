# OCCT Mantis Archive

This repository publishes a static archive of the historical OCCT Mantis tracker.

The archive is intended as a readable long-term reference for past issues, discussions, attachments, and ticket relationships after the original tracker is no longer used as the primary public entry point.

## What is included

- archived ticket pages
- ticket summaries, metadata, and history
- discussion threads and notes
- local copies of preserved attachments
- rewritten internal links between archived tickets

## Archive behavior

The published website is fully static and designed for long-term access through GitHub Pages.

- tickets can be browsed directly by URL
- the main page provides search and filtering
- internal tracker links are rewritten to local archive pages where possible
- references to unavailable tickets lead to a local placeholder page instead of the old tracker

## Privacy and identity handling

This archive is published in anonymized form.

- person profile links are removed
- visible user references are replaced with anonymous aliases
- the public site does not expose the original identity mapping

## Attachments

Attachments are preserved as part of the archive when available.

Some files may be transformed for web publication efficiency, for example:

- large CAD or text-like technical files may be stored in compressed form
- oversized raster images may be resized for web delivery

These changes are made only to support long-term static hosting and practical distribution of the archive.

## Using the archive

If you are looking for the archive itself, use the published GitHub Pages site associated with this repository.

## Scope

The archive is provided as a historical reference. It should not be treated as the active issue tracker for current OCCT development.
